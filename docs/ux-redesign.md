# 画面の作り直し（2026-11-07）

## なぜ作り直すか

ホームに、予定・空き時間・自分の薪・カジリが届けたもの・締め切りの札・丸太の一覧・＋・「今日」・予定を足す・4象限が同時に出ていた。
どれも同じ強さで並ぶので、開いたときに「いま何をすればいいか」が分からない。先延ばししがちな人のアプリなのに、ホームが選ぶものだらけだった。

いちばん Kajiri らしいのは「この1本だけ」の画面（薪1本と［できた］［あとで］だけ）。**ホームもこの考えに寄せる。**

## 誰が、いつ開くか

- 大きなことを後回しにしがちな人。開くのは「何かやらなきゃ」と思ったとき、朝の通知を押したとき、思いついたことを投げたいとき
- 知りたいのは「**いま何を1つやればいいか**」。全体の地図ではない
- 全体（丸太ごとの進み具合・予定）は、たまに見に行く

## 物（オブジェクト）

| 物 | 中身 | 開くと |
|---|---|---|
| 丸太 | 投げた大きなこと。締め切り・なぜやるか・薪の並び | 丸太の画面（薪の一覧・締め切りをカレンダーに入れる） |
| 薪（じぶん） | すぐ手が動く一歩。何分か・最初の動き | この1本だけ（［できた］［あとで］） |
| 薪（カジリ） | カジリが作る下書き・調べもの | 受け取る（作っている／届いた／つまずいた） |
| 薪（頼む・待ち） | 人に頼む・返事待ち | 丸太の画面の中で見るだけ |
| 予定 | iPhone のカレンダーとつないだ Google の予定 | 予定の画面（準備をかじってもらう・直す） |

## 画面の骨組み

タブを3つにする。ホームの右上に並んでいた行き先のボタンはなくす。

| タブ | 役目 | 主な操作 |
|---|---|---|
| 今日 | いま1つやること | いまの1本を始める・投げる（右下の＋） |
| 丸太 | 投げたもの全部と、どこまで進んだか | 丸太を開く・4象限に切りかえる・週のふりかえり・投げる（＋） |
| 予定 | 1日の線（予定と空き時間）と月 | 日を選ぶ・予定を開く・予定を足す・準備が要りそうな予定を探す・カレンダーの設定 |

## 今日のタブのモード

| モード | この人が開いた理由 | 主役 | 主な操作 | 出さないもの |
|---|---|---|---|---|
| はじめて（丸太がまだ無い） | 何ができるか知りたい | カジリと「投げて」 | 最初の丸太を投げる | 予定の線・週の帯・丸太の一覧 |
| やる（今日の自分の薪がある） | いま何を1つやるか | いまの1本（大きなカード）と、次の予定までの空き時間 | はじめる → この1本だけ | 予定の線・週の帯・4象限・丸太の一覧・ほかの日 |
| カジリの番（今日の自分の薪は無いが、丸太は進行中） | 進んでいるか知りたい | 「いまはカジリと仲間の番」 | 届いたものを受け取る・投げる | 予定の線・週の帯 |
| おわり（今日の分が終わった） | 終わったことを確かめたい | 片づけた本数 | 今日はおしまい・もう1本だけ | いまの1本・予定の線 |

- カジリが届けたものは、どのモードでも**1か所**（「カジリから届いた」）にまとめる。ホームに何本も並べない
- 今日の残り（2本目・3本目）は、いまの1本の下に小さく出す。押せば「この1本だけ」
- 予定は、いまの1本のカードの中で「次の予定 13:00 歯医者まで 2時間44分」と1行だけ言う。線は予定のタブ

## 言葉

画面に出す言葉を減らす。世界観の言葉は「丸太」と「薪」と「かじる」だけ残す。

| 前 | 後 |
|---|---|
| 今日かじる / 貯めておく / 運んでもらう / 川に流す（4象限の名前） | 今日やる / あとでやる / 任せる / やらない |
| カジリが運んできた | カジリから届いた |
| 受け取った（済みにする） | 受け取った |
| ダム ◯本 | 片づけた薪 ◯本 |
| 川辺の地図 | 4象限 |
| 仲間に頼む | 頼む |
| 川に流す（下流に残しておく） | やらない（消さずに残す） |

## 消したもの・移したもの

- ホームの自前の見出し（大きな日付・「今日」・予定を足す・4象限のボタン）→ タブとナビバーへ
- ホームの下からのぞく丸太の一覧 → 丸太のタブ
- 月の表示のいちばん上の「準備が要りそうな予定を探す」→ 予定のタブのナビバーのボタン
- 月の表示の下の Google カレンダー・予定が出ないとき → 予定のタブの「カレンダーの設定」
- Kajiri について（プライバシーなど）→ 丸太のタブのいちばん下
